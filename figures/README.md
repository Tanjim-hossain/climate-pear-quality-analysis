# Figure sources

All PNGs here are regenerated by `scripts/verify_data.py` from the included complete raw datasets. No mixed-model fitted results are substituted into these descriptive figures.

| File | Data and meaning |
|---|---|
| quality-distribution.png | Harvest quality by climate and country; n=1,942 |
| growth-trajectories.png | Mean observed size at all 20 scheduled weeks; n=192 pears at baseline |
| retention.png | Observed measurement fraction at each scheduled visit, by variety |
| soil-pca.png | PCA variance and first two observation scores; 96 trees, 17 standardized features |
| soil-lda.png | LDA fitted scores; 96 trees, 17 soil variables plus harvest count |

These displays supplement the full editable analysis code. PCA biplot arrows, the LDA coefficient workflow, individual growth trajectories and the broader exploratory plotting sequence are available in `analysis/r`; the retained soil PDF provides the corresponding PCA/LDA technical output.
