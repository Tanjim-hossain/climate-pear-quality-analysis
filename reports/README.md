# Retained technical reports and outputs

This folder keeps the technical PDF outputs that remain useful for reproducing and reviewing the portfolio analysis without publishing historical documents that contain outdated contributor metadata.

- [soil-analysis.pdf](soil-analysis.pdf): PCA/LDA code, plots and interpretation used as the source for the editable soil workflow.
- [longitudinal-sas-source.pdf](longitudinal-sas-source.pdf): the supplied two-page SAS printout. The printout is truncated mid-statement, so use the complete `.sas` workflow in `analysis/sas` as the executable source version.

The project narrative, reported model estimates and methodological interpretation are documented in the repository [README](../README.md), [complete analysis guide](../docs/analysis-guide.md) and [source audit](../docs/analysis-audit.md). Re-running `scripts/render_analysis.R` creates fresh portfolio outputs without replacing the retained technical source PDFs.
