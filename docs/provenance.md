The EDA R Markdown copy has portfolio authorship metadata normalized to **Tanjim Hossain**; its analysis workflow is otherwise retained for technical continuity. Historical rendered documents carrying outdated contributor metadata are intentionally not published in this portfolio.

No project-specific power-simulation source or complete final-model SAS log was found. Reported numerical results used in the portfolio documentation are clearly identified as reported values rather than independently re-created model output. The extracted soil source is identified as a PDF transcription, not as a separately supplied original R file.

## Reuse

Data and course materials were supplied for UHasselt coursework. No independent open-data licence was included with the source materials, and this repository does not assign a new blanket licence to the course datasets. Portfolio code and documentation are maintained by **Tanjim Hossain**.
